## 简介

DeepSeek Harness 文件插件 —— 在会话标签栏中新增 **文件** 标签页，用于浏览会话工作区并预览文本文件。

## 功能

- **文件标签页**：与对话、轨迹、终端、Git 并列的新标签页
- **工作区浏览**：逐级列出当前会话工作区中的目录
- **面包屑导航**：随时回到任意上级目录
- **文件预览**：在会话内直接查看文本文件的首屏内容
- **只读**：不会写入、移动或删除任何文件

## 安装

使用 DSH 的添加插件功能，输入包名：`dsh-cool-file`。
