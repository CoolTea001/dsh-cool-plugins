## Description

DeepSeek Harness file plugin — adds a **Files** tab to the session tab bar for browsing the session workspace and previewing text files.

## Features

- **Files tab:** a new tab beside Chat, Trajectory, Terminal, and Git
- **Workspace browsing:** list the session's workspace directories, one level at a time
- **Breadcrumb navigation:** jump back to any parent folder
- **File preview:** open a text file and read its first page without leaving the session
- **Read-only:** the tab never writes, moves, or deletes a file
