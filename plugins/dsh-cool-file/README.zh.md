# dsh-cool-file

## 简介

DeepSeek Harness 文件插件 —— 在会话标签栏中新增文件标签页，展示工作区对应的文件树，支持预览/编辑文件。

## 功能

- **工作区文件树**：根据当前激活会话的工作区展示对应的文件树
- **预览/编辑文件**：支持预览/编辑文件、代码高亮

## 安装

使用 DSH 的添加插件功能，输入包名：`dsh-cool-file`
