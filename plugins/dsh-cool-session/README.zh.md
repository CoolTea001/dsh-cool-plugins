## 描述

DeepSeek Harness 会话管理插件 —— 工作区会话列表菜单中添加删除会话功能，设置面板中支持批量管理会话（归档、删除）

## 功能介绍

- **删除会话：** 工作区会话列表操作弹窗中新增「删除会话」选项
- **批量管理：** 设置面板中支持批量管理会话（归档、删除）

## 安装教程

使用 DSH 的新增插件功能，输入包名：`dsh-cool-session`。
